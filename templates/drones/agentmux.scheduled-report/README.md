# Scheduled report

One agent answers your question on a schedule, and the answer is sent to an agent of yours as a message.

Change first: the question (`question`) and who gets the report (`owner`). The schedule is Mondays at 09:00 UTC; edit the job's trigger to change it. Each run is capped at 2 dollars.

Test payload: run it once by hand from the Jobs tab; nothing is written outside AgentMux.
