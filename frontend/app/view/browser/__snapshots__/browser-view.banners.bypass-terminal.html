Korp asks you to auto-approve its clicks:
On a.example, for 1 hour: its clicks that submit, delete or send go through without asking you, and so does the page's own "Are you sure?" that follows one. It still can't type passwords or codes or run scripts, and payments still ask. Stop it any time from the red strip.
It also asks to run commands in the terminal on a.example: it types real keys and presses Enter with no question per line. You can read every line in the pane's Log, and Stop or Pause end it at once. Passwords and codes stay yours to type. One limit: Between lines the agent waits about 2.6 seconds and reads the screen for a password or code prompt before it types the next line, so a prompt that appears later (ssh to a slow host, say) can still get the next line typed into it. Run such a command yourself.
