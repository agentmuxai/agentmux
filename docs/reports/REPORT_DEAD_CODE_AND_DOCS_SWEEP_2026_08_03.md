# Report: Dead-code + docs cleanup sweep (2026-08-03)

**Author:** AgentO (multi-agent workflow, `wf_998d88e3-ab0`, 259 subagents, ~9.8M tokens, ~10.8M ms wall time)
**Scope:** Rust workspace (agentmux-cef/agentmux-srv/agentmux-launcher/agentmux-common), frontend (SolidJS/TS), and all 967 files under `docs/`.

## Methodology

1. **Rust**: `cargo check --workspace` on macOS produced 103 real `dead_code`-family compiler warnings across 4 crates. Each warning is ground truth from the compiler, not a heuristic.
2. **Frontend**: `knip` (unused-file/export/dependency finder) produced structured JSON findings: unused files, unused exports, unused exported types, unused deps/devDeps, duplicate exports.
3. Every candidate was routed to a dedicated verify agent (one per file) with explicit instructions to grep the whole repo and rule out known false-positive patterns in this codebase before conceding "dead": platform-`#[cfg]`-gated code compiled out on macOS, string/enum-keyed IPC dispatch, `#[cfg(test)]`-only usage, barrel re-exports, dynamic/platform-conditional file resolution, and CLI/test-harness entry points invoked by path rather than import.
4. **Docs**: 20 parallel discover agents swept all 967 `docs/*.md` files (default bias: keep — this repo intentionally keeps a per-task paper trail of SPEC/STATUS/REPORT/PLAN/retro docs), each followed by an independent adversarial verify pass before a candidate was accepted.
5. A handful of platform-variant files (`*.darwin.*`/`*.win32.*`/`*.linux.*`) and vendored `public/fontawesome/*.min.css` assets were excluded from the sweep up front as known false-positive patterns (confirmed from this session's own tab-redock work) rather than spending a verify pass on them.

**This is a findings report, not an executed cleanup.** Nothing below has been deleted yet.

- The Rust "dead" verdicts assume a macOS `cargo check`. A couple of borderline cases were explicitly reasoned through cfg-gating rather than compiled on Windows/Linux to confirm — worth a `cargo check --target x86_64-pc-windows-msvc` (or CI) sanity pass before merging removals, in case something was missed.
- Frontend spot-check: `frontend/app/store/global.ts`'s ~40 flagged exports were independently re-verified by hand (not just trusting the agent) — confirmed genuinely dead as a stale backward-compat re-export barrel; the underlying atoms live on via `frontend/app/store/window-identity.ts`, which is what all real consumers import from. This pattern (a module re-exporting symbols nobody imports from *that path* anymore) likely explains a meaningful fraction of the 327 partial-export findings — recommend a `npm run build` + `tsc --noEmit` pass after each batch of removals rather than one giant PR.
